# AoD Game Night – narrated companion site

A local, offline website for playing the *AoD Adventure Book* campaign at the table:
narrated story with a separate voice per character, setup and rules reference,
interaction choices, and trackers for each adventure.

## Run it

```
./start.sh          # → http://localhost:8000  (this PC only)
```
Opening `index.html` directly also works in Chrome. The home page lists all parts and
`index.html?c=ch07` opens a specific one.

## What the app shows per part

- **Story:** scenes with `tab: "story"`, with a ▶ Narrate button and line-by-line highlighting. Tap a line to start from it.
- **Setup & Rules:** the setup map, the setup checklist and the rules cards. Hidden if the part has none (interludes).
- **Play:**
  - Each Book of Interactions page, as its picture with clickable #markers plus a list of the choices.
  - Clicking a choice opens the outcome in a reader, which narrates it and offers follow-up dilemmas.
  - A "read #…" box opens any outcome by number.
  - "Events" (scenes with `tab: "play"`), then the plugin and the generic trackers.
- **Ending:** `tab: "ending"` scenes, then the rewards and the next part.
- **Saved progress:** tracker and checklist state is saved per part in localStorage. Reset it with the button on the Play tab.
- **Plugins:** chapter-specific widgets live in `PLUGINS` at the bottom of `app.js`. `init(api)` draws the widget, and
  `onScene(id)` runs when an outcome is opened. Chapter 06 uses one for the Collapsing Roof rune track,
  where the lever outcomes open doors.

## Rules lookup (home page)

The search box on the home page searches `data/rules.js` (`window.RULES`, about 225 cards). Each card has a
`title`, `category`, `tags` (synonyms players might type), `text` (a short summary in our own words, simple
HTML allowed) and `page` (the Rulebook page). The cards were written from `AOD_Rulebook-2022-1.5.pdf`, with the errata
(`Remake Errata_1.5_(7-6).pdf`) applied and marked "(errata)". The search runs offline in the browser: it ignores
filler words, accepts prefixes and small typos, and ranks title > tags > text. `index.html?q=burn` opens with a search
already filled in. To add or fix an answer, edit the card in `data/rules.js`; nothing needs rebuilding.

## Folder layout

```
index.html  app.js  style.css      the app (one page, everything is driven by data)
data/parts.js                      list of available parts (home page) – edit by hand
data/<id>.json                     SOURCE content of one part, written by hand from the book
data/<id>.js                       GENERATED by tools/build_audio.py (json + audio paths) – the app loads this
audio/<id>/*.mp3                   GENERATED narration clips
img/<id>-header.jpg                banner art (cropped from the PDF, without the baked-in title)
img/<id>-setup.jpg                 setup map (optional)
tools/extract_pages.py             PDF → reading-order text with [H]/[I]/[B] tags
tools/build_audio.py               JSON → narration MP3s (Piper neural TTS, local) + data/<id>.js
tools/setup_tts.sh                 one-time: venv with piper-tts + pymupdf, downloads voice models
```

## Adding a new part (the recipe)

Sources in `~/Downloads` (PDF page numbers equal the printed page numbers):
- `AoD_AdventureBook_v1.0_n.pdf`: the chapters (table of contents on page 2), and at the back
  (pages 84–117) the numbered interaction **outcomes** (#01, #02, …).
- `AoD_InteractionsBook_v1.0_n.pdf`: one full-page illustration per "Book of Interactions page NN".
  The choices are printed on the picture as numbered eye markers (e.g. page 17 → #72–#75). The labels are
  part of the image, not text, so read them from a rendered preview.
- `AOD_Rulebook-2022-1.5.pdf`: general rules. Use it for keywords (FOCUS, SHIELD, PREVENT, Recall
  Action, Monster Raid, Companions) when a rules card needs more context.

1. **Tools (once per machine):** `tools/setup_tts.sh` creates `~/.cache/aod-tts/venv` and
   downloads the voices to `~/.cache/aod-tts/voices`. Set `V=~/.cache/aod-tts/venv/bin/python`.
2. **Extract text** in true reading order (the book is two-column):
   `$V -I tools/extract_pages.py <pdf> FIRST LAST > /tmp/chNN.txt`
   Tags: `[I]` italic = read-aloud story, `[B]` bold = rules, `[H]` heading.
   Also render previews to check column order and pictures:
   `pdftoppm -f FIRST -l LAST -r 60 -png <pdf> /tmp/pg`.
3. **Interactions:** for every "Book of Interactions page NN" that the chapter or its outcomes mention,
   render that page (`pdftoppm -f NN -l NN -r 110 -jpeg -jpegopt quality=82 -singlefile
   <interactions pdf> img/boi-NN`) and read its numbered choices. Then take each outcome's text from
   the Adventure Book dump of pages 84–117 (`#72: Introduce yourself as a friend` …). Outcomes can
   offer follow-up dilemmas (`#76 – Suggest that he goes along with you`), which go into `choices`.
   An outcome may also send you to another Book of Interactions page; add that page as another entry in
   `interactions`.
4. **Images:** crop at 150–200 dpi with
   `pdftoppm -f P -l P -r 150 -x X -y Y -W W -H H -jpeg -singlefile <pdf> img/<id>-header`.
   For the header, crop the art to an area **without** the printed chapter title, because the app draws its own.
5. **Write `data/<id>.json`** (format below). Split every paragraph into speaker lines so that dialogue
   gets the character's voice and the "he says" parts stay with the narrator. Copy the book text
   exactly. Only remove the quotation marks around dialogue (the app adds them back).
6. **Render audio:** `$V -I tools/build_audio.py data/<id>.json --voices ~/.cache/aod-tts/voices`.
   Clips are cached by text + voice settings, so editing one line re-renders only that line.
7. **Register** the part in `data/parts.js`. Then open `index.html?c=<id>` and check that every tab
   renders.

## Part JSON format

```jsonc
{
  "id": "ch07",                       // also the file name and the audio folder
  "kind": "Campaign",                 // "Campaign" | "Interlude" | "Battleground"
  "number": "07",
  "title": "The Galleries Under the Mountain",
  "pages": "32–35",
  "header": "img/ch07-header.jpg",
  "setup": "img/ch07-setup.jpg",      // optional
  "setupNote": "Table space 84 × 56 cm …",   // optional, shown under the map
  "cast": { "narrator": {…}, "tharmagar": {…}, "rules": {…}, "simon": {…} },   // copy presets below
  "checklist": ["Build the map as shown …", "…"],      // setup steps, ticked off in the app
  "rules": [                                          // Setup & Rules tab cards (simple HTML allowed)
    { "title": "Darkness behavior – Standard", "html": "The Darkness will chase …" },
    { "title": "Winning & losing", "html": "…", "tone": "danger" }
  ],
  "scenes": [
    {
      "id": "intro",
      "tab": "story",                 // story | play | ending | interaction
      "title": "Into the Galleries",
      "kicker": "Read aloud before setup",   // optional small label
      "paragraphs": [
        [ ["narrator", "The galleries seem endless, …"] ],
        [ ["simon", "Who the hell are you!?"], ["narrator", "He rants, startled, …"] ]
      ],
      "choices": ["i76", "i77"],      // optional – buttons that open other scenes (dilemmas)
      "choiceNote": "Choose as a group; a tie is decided by the Party Leader."   // optional
    },
    { "id": "i72", "tab": "interaction", "title": "#72: Introduce yourself as a friend", "paragraphs": [ … ], "choices": ["i76","i77","i78"] }
  ],
  "interactions": [                   // Book of Interactions pages, shown on the Play tab
    { "label": "Tomb Robbery", "page": 17, "image": "img/boi-17.jpg",
      "when": "At the start of the adventure",          // when the players open this page
      "options": ["i72", "i73", "i74", "i75"],
      "hotspots": { "i72": [45, 12], "i73": [65, 36] } } // optional: % x/y of each eye marker on the picture
  ],
  "trackers": [                       // generic widgets on the Play tab
    { "type": "flip",    "id": "hunt",  "label": "Darkness Hunting card", "faces": ["A","B"], "note": "Flip after it triggers" },
    { "type": "status",  "id": "tharm", "label": "Tharmagar", "states": ["LOYAL","DEFEATED"], "bad": ["DEFEATED"],
      "alerts": { "DEFEATED": "The adventure ends in failure." } },
    { "type": "counter", "id": "piles", "label": "Runes set aside", "min": 0, "max": 15, "start": 15, "note": "…",
      "alerts": { "0": "No Runes left to form a Pile." } },
    { "type": "checks",  "id": "keys",  "label": "Runekeys", "items": ["Grey","Green","Orange","Red"] }
  ],
  "rewards": "Each player chooses and unlocks a <b>Class Ability</b> for their Hero.",
  "next": "Interlude 01 – Making Amends (page 31)",
  "plugin": "ch06"                    // optional: custom Play-tab code in app.js (PLUGINS.ch06)
}
```

Speaker keys in `paragraphs` must exist in `cast`. A `rules` line is shown as a gold rule box and is only
read aloud when "Also read rule text" is on.

## Voice presets (Piper, local)

Every voice is a Piper model in `~/.cache/aod-tts/voices`. `length_scale` above 1 is slower,
`pitch` below 1 is deeper, and `fx: "ghost"` adds echo and a muffled tone.

| key / role                  | voice                                    | extra                                      |
|-----------------------------|------------------------------------------|--------------------------------------------|
| `narrator`                  | `en_US-ryan-high`                        | `length_scale 1.12`                        |
| `tharmagar` (old sage)      | `en_GB-alan-medium`                      | `length_scale 1.12, pitch 0.93`            |
| `rules`                     | `en_US-lessac-high`                      | –                                          |
| rogue / young man           | `en_GB-semaine-medium`, `speaker_id 1`   | `length_scale 1.05`                        |
| gruff man / dwarf           | `en_GB-northern_english_male-medium`     | `pitch 0.86, length_scale 1.08`            |
| ghost                       | `en_GB-northern_english_male-medium`     | `pitch 0.82, length_scale 1.15, fx "ghost"`|
| gloomy / old man            | `en_GB-semaine-medium`, `speaker_id 2`   | –                                          |
| woman                       | `en_GB-cori-high`                        | –                                          |
| young woman                 | `en_GB-semaine-medium`, `speaker_id 3`   | –                                          |
| stern woman                 | `en_GB-semaine-medium`, `speaker_id 0`   | –                                          |

Reuse the same key and preset for a recurring character across parts, so they always sound the same.
Recurring characters so far: `narrator`, `tharmagar`, `rules`, `simon` (Simon Klibisch, rogue preset),
`lakin` (King James Lakin, ghost preset).
